# Cyberduck — Free Offline Installer

![Category](https://img.shields.io/badge/File_Transfer-blue?style=flat-square)

## About

Cyberduck is a free, open-source cloud storage browser for Windows and macOS supporting FTP, SFTP, WebDAV, Amazon S3, Google Cloud Storage, Microsoft Azure, and Backblaze B2. Browse, upload, download, and manage files on remote servers and cloud storage services with a familiar Finder/Explorer-like interface. Cyberduck's wide protocol support makes it a universal file transfer and cloud browsing tool.

## Common Problems & Limitations

- **Not a Sync Tool** — Browse and transfer only; not a sync client like Dropbox or OneDrive
- **Commercial Mountain Duck** — Full drive-mounting experience requires paid Mountain Duck sibling product
- **Transfer Speed** — Not the fastest transfer client for very large file sets
- **Server-Side Operations** — Some operations like remote folder moves require download-upload
